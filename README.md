# About me

I like taking a rough problem and turning it into **something useful in production**. Most of my work is around React, Next.js, TypeScript, Node.js and AWS serverless — building new products, improving existing ones and fixing the parts that get in the way.

When a project needs direction, I'm happy to step in: make decisions, build the foundations, unblock people and **still write code**. I prefer practical solutions, clear communication and getting things shipped without unnecessary ceremony.

# Projects worth exploring

### [`aws-ts-lambda-template`](https://github.com/thi-days/aws-ts-lambda-template)

A look at how I like to set up a **clean, modern Lambda project**: strict TypeScript, typed handlers, CDK, Powertools, Jest and OIDC-based deployments. It's small enough to understand quickly, but organized to grow without turning into a mess.

### [`simple-local-rag`](https://github.com/thi-days/simple-local-rag)

I built this to understand **how RAG works end to end**, not just call an API and hope for the best. It covers ingestion, embeddings, retrieval, tool calling and source-backed answers, with an honest README about what would need to improve before production.
