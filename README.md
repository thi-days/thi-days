# About me

As a **Software Engineer**, coding has been only part of the journey - even more now in the AI era. I believe that **ownership** of product flows end-to-end is where the real value of an engineer lies.

So, daily I **gather requirements** with stakeholders, **make architecture decisions** (benefits x trade-offs), guide the implementation (using AI agents, sure), and validate the delivery.

# AI in the workflow

**AI agents is a crucial part of how I deliver software nowadays.** And more than ever, the good old **SDLC** keeps being important:

1. I look up the requirements with POs, PMs, and so on.
2. Then I design the architecture.
3. Break it down into small testable tasks.
4. Hand them over to coding agents (with tests, etc).
5. Review their output and validate the delivery.

**Architecture decisions and technical accountability remain with me.**

# Projects worth exploring

### [`distributed-rate-limiter`](https://github.com/thi-days/distributed-rate-limiter)

A **distributed systems case study** implementing shared per-client rate limits across three API instances with a load balancer in the front.

The project connects **requirements** to **architecture decisions**: shared atomic counting, fixed-window trade-offs, fail-open behavior, and Redis connection failure and recovery. **ADRs explain the alternatives and operational limits.**

Automated tests run concurrent requests, client isolation and Redis connection failure.

**Tech:** _Redis, Nginx, and Docker Compose_.

### [`aws-ts-lambda-template`](https://github.com/thi-days/aws-ts-lambda-template)

A deployment-tested **AWS Lambda service template** with strict TypeScript, CDK infrastructure, Powertools observability and GitHub Actions deployment through OIDC.

I defined the architecture, environment separation and quality gates, directed coding agents through implementation and review, and validated the template by deploying it to a real AWS account.

### [`simple-local-rag`](https://github.com/thi-days/simple-local-rag)

An **end-to-end RAG application** with Next.js, OpenAI and ChromaDB, covering document ingestion, chunking, embeddings, retrieval, tool calling and answers linked to source documents.

The repository documents the implementation and its limitations, including the changes needed to move beyond a local learning environment.
